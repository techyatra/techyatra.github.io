Video slide generator — at a glance

This is a separate page from your home portfolio. You paste a script; Google Gemini (through a Cloudflare Worker) returns structured JSON; your browser turns that into real slides. PNG/PDF export uses libraries in the page — nothing is uploaded to a “slide server.”

Not the portfolio site. This tool does not use Hashnode, YouTube RSS, or the same Supabase tables as the homepage contact form. The Worker URL is the only “server” your script talks to for AI and for logging.

Read this like a story
  • Green — The generator is a static file. After AI responds, the page builds the deck with normal HTML and CSS (hooks, lists, quotes, code, etc.).
  • Orange (Worker) — Keeps Gemini keys off GitHub. /generate does the model call; /log records optional usage metadata.
  • Purple (Gemini) — Produces a single JSON document describing many slides. Your code repairs and parses that JSON client-side if needed.
  • Teal (Supabase) — Receives what the Worker forwards to /log, not a direct public Supabase key in this HTML for that path.
  • Indigo (Export) — png/pdf are created on your machine by rasterizing the live slide; files save locally — no “upload deck to cloud” step.
